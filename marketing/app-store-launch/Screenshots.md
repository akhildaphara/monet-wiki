The 6.3-inch set was captured on the repository’s iPhone 18 Pro simulator. The 6.9-inch set resizes the same captures to Apple’s accepted large-display dimensions. All PNG files are opaque RGB. The screenshots show a sample wallet and sample spend from the current app interface. A temporary simulator-only build supplied the catalog and guest session locally because the release build could not reach the API from this environment.

The Xcode project also targets iPad. Apple lists 13-inch iPad screenshots as required for iPad apps. This package covers the two requested iPhone sizes.

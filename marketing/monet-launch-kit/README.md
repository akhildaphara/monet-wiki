# Monet launch kit

Four deterministic marketing exports built from Monet’s current design system and supplied app screenshots.

## Exports

- `monet-hero-1600x900.jpg` — landing-page hero
- `monet-social-1080x1350.jpg` — social feed post
- `monet-story-1080x1920.jpg` — vertical story
- `monet-launch-1200x1200.jpg` — square launch card

The source-preservation inputs are listed in `manifest.json`. To regenerate the set after changing copy or layout, run:

```bash
python3 marketing/monet-launch-kit/generate.py
```

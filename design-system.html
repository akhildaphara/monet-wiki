Monet Guidelines

Monet is a native iOS app with its own product identity — a financial optimizer that feels premium, native, and energetic. The rules below are Monet-specific decisions.

Section Headers

Two semantically distinct styles — both purposeful, neither generic.

Section style .section — default

Used to divide distinct content areas within a scrollable screen (e.g. "Cards", "Preferences", "Rewards breakdown").

  • Font: .title3.bold() — 20pt, bold
  • Color: .primary
  • Case: sentence case
Rewards breakdown See all

Group style .group — list label

Introduces a grouped list. Deliberately recedes — the list content should dominate. Title-case the string at the call site.

  • Font: .caption.semibold — 12pt, semibold
  • Color: .secondary
  • Case: Title Case — capitalize each word at the call site
Linked Institutions

Why we differ from Wise: Wise uses a prominent group header. Monet uses a small, muted caption — visually quiet so the list takes focus, while title case keeps it readable and polished.

Typography Case Rules

Case is intentional and consistent — no exceptions.

BUTTONS Sentence case — "Add a card" not "Add A Card"
NAV TITLES Title case — "Wallet", "Insights", "Account"
SECTION Sentence case — "Rewards breakdown"
GROUP Title Case — "Linked Institutions", "Recent"
BODY Sentence case. Never title case body copy.

Loading States

Wise: progress bars for fast tasks; spinners for stressful ones. Monet adds a third state — the Tapestry — for the most immersive transitions.

Thin progress bar
Background sync, link token fetch, short data loads (200ms–700ms). Sits at the bottom of the persistent header or below the triggering button. Never embedded inside a button label.
Spinner (ProgressView())
Stressful / long tasks: Plaid account load, full-page cold start when no cached data exists.
AnalyzingTapestryView
AI analysis, insights recalculation. Overlays the existing content (Doherty mitigation) — data stays visible, dimmed and blurred. The "magic moment" of the app.

Notifications & Feedback

Snackbar

Non-critical, auto-dismissing confirmation. Appears bottom-anchored, above the tab bar. 3 words or less. Optional single Undo action.

  • Background: near-black (#1a1a1f)
  • Text: white, .footnote.semibold
  • Action: Theme.primaryGreen
  • Auto-dismiss: 2.4 seconds
  • Only one visible at a time — new ones replace old

Nudge

Persistent, inline informational strip. Four semantic types: info, success, warning, destructive. Used inline within content, never as a toast.

Design Guidelines

UX Writing & Voice

Tone: Delightfully simple, authentically expert, and highly energetic. Monet makes credit card optimization feel like magic, not accounting.

  • Sentence Case: Always use sentence case for headers, buttons, and list items. (e.g. "Add a card", not "Add A Card").
  • Active Voice: "You earned $5.00" instead of "$5.00 was earned".
  • Contractions: Use them to sound human. "We're", "You've", "Can't".
  • Conciseness: Write headlines as if subcopy is illegal. Zero jargon.
Use: "Rewards", "Cards", "Wallet", "Get more from your cards."
Banned: "Bank", "Banking", "Agent" (use "Support Team"), "Optimize Portfolio Utilization" (too jargon-heavy), "Rebates."

Visual Assets

Icons

Monet exclusively uses SF Symbols to ensure flawless alignment with iOS, maintaining strict visual rules:

  • Less is More: Use the default standard weight. Avoid multi-colored or highly complex symbol variants for standard UI.
  • Clarity over Cleverness: Icons must be universally understood instantly.
  • Interactive vs. Informational: Interactive icons use primary or neutral foreground colors; informational icons in lists should be secondary.

Tapestries & Illustrations

For empty states or moments of high celebration, we use "Tapestries"—rich, textural illustrations utilizing generic, 3D floating primitives or vibrant color meshes to inject energy and delight.

Do's and Don'ts

Do

  • Use system rounded font design (design: .rounded) with heavy weight for the Monet brand title across the app.
  • Use continuous corner radii for all surfaces (style: .continuous).
  • Use Theme.primaryGreen (not Color.green) everywhere the brand green appears.
  • Use Theme.warningOrange for missed-earnings and nudge states.
  • Maintain 20px uniform padding inside cards.
  • Use the canonical spring presets from the Motion section.

Don't

  • Use gradient text (foregroundStyle(gradient) on Text). Banned.
  • Use Color.green, Color.orange, Color.red directly — always use Theme tokens.
  • Use .cornerRadius(X) (non-continuous) — always .clipShape(RoundedRectangle(cornerRadius: X, style: .continuous)).
  • Use generic "AI slop" patterns, glassmorphism, or the hero-metric template.
  • Overwhelm the user with spreadsheet-like data; focus on the optimal recommendation.

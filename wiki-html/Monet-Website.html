The Monet-Website is the public-facing landing page for the Monet-App-Overview application. Built with Astro v5, it showcases the app's core features, hosts the companion PWA client, and serves as the entry point for new users to join the waitlist.

Tech Stack

  • Framework: Astro v5
  • Language: TypeScript
  • UI: Tailwind CSS 4, Vanilla JS & CSS transitions, Lucide HTML paths
  • Dev Server: Runs on port 3001 (astro dev --port 3001)

Design

  • Dark-mode-first design with an accent green (accent-green) color scheme.
  • Uses Inter font family for its neutral, modern feel and broad compatibility.
  • Smooth, high-performance CSS transition entrance animations.
  • Glassmorphic glow effects behind app screenshots.

Page Structure

The website is built with these main pages:

  1. Landing Page (index.astro): Single-page layout featuring navigation, theme toggle, hero section, interactive merchant search preview, a waitlist signup card (integrated with Formspree honeypot anti-spam), and waitlist success states.
  2. Companion PWA Client (app.astro): Interactive web app shell mounted at /app with search, wallet setup, and offline fallback screens. Integrated with geolocation queries and custom theme overrides.
  3. Contact Page (contact.astro): Help form using Formspree asynchronous POST routing.
  4. Privacy & Terms (privacy.astro, terms.astro): Privacy and service agreements.

Universal Links

The website hosts the /.well-known/apple-app-site-association file, enabling Universal Links support.

Running Locally

cd raw/website
npm run dev   # → http://localhost:3001

Repository & Deployment

  • Hosted in the raw/website directory.
  • Deployed via Firebase Hosting. The build process runs static export (npm run build outputs to /out) which is deployed to Firebase.
  • Current HEAD: d2c7985 (Standardized component naming and design system mappings).

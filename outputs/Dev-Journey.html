Development Retrospective · Jan–May 2026

Four months, two repos, one question: which card should I use?

Monet is a credit card rewards optimizer. You search a merchant, and it tells you which card in your wallet to pull out — the one that earns the most for that purchase. I built it solo across a SwiftUI iOS app and a serverless TypeScript backend on AWS. This is the story told through 362 commits, a lot of deleted code, and a few very honest one-liners.

I started on January 23, 2026 with an empty Xcode project and a hypothesis: if I could categorize a merchant correctly, I could tell you which credit card earns the most. Four months later, Monet has Plaid bank linking, spend insights, a recommendation engine with RankedSpend optimization, guest mode, SSL pinning, and a design system named after the app itself. No release tags. Just continuous shipping.

Act I "Can AI tell me which card to use?" Jan – Feb 2026

The iOS repo's first real commit after the scaffold was blunt: init categorizer using gemini api (9a2d5cd, Jan 24). Four days later I pivoted: use local api instead of gemini api (68970df). The backend was born the same week: an Express-style Node server with a /categorize endpoint (e7c0635, Jan 28), then a TypeScript migration on Feb 7.

February is when the product found a voice. On Feb 18 I added Google Sign-In, switched to Apple MLKSearch for on-device categorization, and moved card recommendations local: hook card reccomendation based on category locally, remove reccomendation api call (e6084d6). Then came Feb 22: nineteen commits in a single day. Places API integration, fuzzy brand matching, a sunset-themed UI overhaul (400a5c5), quick search chips, card nicknames, and an APIClient refactor that deleted 779 lines of local categorization code (e0c9bd4).

Two days later, on Feb 23, the backend absorbed what the phone had been doing locally: transfer brand categorizer and data from iOS app to backend (b9b28d7, +3,543 / −429 lines). Card catalogs moved server-side. The categorization brain trust now lived in one place, and the phone went back to doing what phones do well: showing things to a human.

Act II "Connect the bank, see the damage" Mar – Apr 2026

March was quieter (12 iOS commits, 6 backend) but foundational. I added network monitoring and offline UI on the app side (2e37ce8), and on Mar 9 both repos landed their first Plaid integration within hours of each other: Link flow on iOS (08d7222), endpoints on croe (5b8003c, 01a26ac).

April is where things got messy and productive at the same time. Apr 4 brought InsightsView and a major navigation restructure on iOS (3e24961, +866 lines) while the backend expanded Plaid with link tokens and DynamoDB transaction storage (95a0200). Then, on Apr 15 at 00:50, I deleted Plaid from the iOS app entirely:

The second Plaid integration was deliberate: multi-account support, webhooks, bank-to-card mapping, offline-resilient networking, insights caching with TTL. Apr 25 on the backend was a monolith split: 48 files touched, 826 lines removed from index.ts, modular routes born (d7a5cc9). Apr 26 added serverless.yml and JWT authorizers (7f74180, be655d1). Hours later, 13f8778 switched it back to transactionId plus a DateIndex LSI. iOS followed with matching transaction model refactors (e893776, c2d455d). The repos were finally speaking the same language, even when that language changed twice in one day.

Act III "Make it feel like a real app" May 2026

May accounts for 50% of all iOS commits (113 of 225) and 44% of backend commits (60 of 137). The first two weeks were a design-system explosion: swiftui-pro first pass (384e3c2), a premium animated LoginView (bb752ce), MonetListItem and MonetCard components, iOS 18 TabView syntax, and the largest single refactor in iOS history (a17d46b: +1,174 / −1,305 lines, 15+ components extracted). Gemini was fully excised from both repos (8f2f436 iOS, 5cbd76f backend). Bilt 2.0 Blueprint landed on both sides (533499c, 58f9903).

Then, on May 10, both repos went quiet. The last iOS commit was 2b7ecaa, and nothing followed for nearly three weeks. The honest explanation isn't an architecture pivot or a stuck bug — I went to France on vacation. The graph flatlines because I was somewhere with better food and no laptop. Best refactor of the whole project.

Act IV "Make the optimizer smart, then ship beta" May 27 – 31, 2026

The final week was a blitz. Backend: AWS Bedrock for unknown merchants (0dd07e4, 5f3aa87), RankedSpend optimization (4ac3214), O(N) scan to O(1) index lookup for Plaid webhooks (6f2fe97), guest JWT auth and rate limiting (May 31), and an opus 4.8 security review pass (c0bf3ae, 28 files). iOS: 946 lines of unit tests (820d0d8), incremental Plaid sync (60a1277), guest mode with custom AuthService (926c752, +1,007 lines), SSL certificate pinning (cd31565), and a full day of guest-to-account merge bug fixes.

The last iOS commit on May 31: feat: implement category fallback chain in RewardStore (93f0a75). The last backend commit the same day: feat: aggregate descendant category spend for cap tracking (8a0892b). Still building. Still no tags.

Aha Moments

iOS The Gemini Four-Day Experiment

Jan 24: adopted Gemini for categorization. Jan 28: pivoted to local API. Feb 18: Apple MLKSearch. Feb 23: deleted local Places/brand maps, moved categorization server-side. May 7: removed the GoogleGenerativeAI package entirely.

Lesson: Categorization bounced between cloud AI, on-device heuristics, and backend API for months before settling on server-side recommendations with local fastCategorize for instant UX.

Both The Plaid Yo-Yo

Mar 9: first integration. Apr 4: Insights built on Plaid. Apr 15 00:50: remove plaid (−975 iOS, −598 backend). Apr 15 afternoon: SwiftData DataStore + error handling refactor. Apr 24: add plaid on both repos, rebuilt through DataStore and modular routes.

Lesson: Not a revert. A deliberate teardown to introduce persistence-first architecture, then reintegration nine days later with multi-item support and webhooks already planned.

Backend The Schema Pivot (Same Day)

9de0ed0: replace transactionId with dateAndId as DynamoDB sort key. 13f8778 hours later: back to transactionId + DateIndex LSI.

Lesson: Composite sort keys looked elegant for date-range queries but coupled identification to dates. The team settled on transactionId + LSI within hours of trying the alternative.

Backend O(N) → O(1) Webhook Lookup

6f2fe97: "replace O(N) full-table scan with O(1) index lookup for getUserByItemId using a new MonetPlaidItemIndex DynamoDB table."

Lesson: Plaid webhooks need to resolve users by item_id. Scanning the users table doesn't scale. A dedicated index table was the fix.

Both The RankedSpend Bug Wave

May 31 sequence: quarterly rotating bonuses added (3adb688), Zolve rewards reverted (ef0a0a4), fix preventing RankedSpend from claiming RotatingCategory bonuses (69b8b48), centralized claiming logic (88dfb58). iOS mirrored with rankedSpendRules refactors May 9–10.

Lesson: Complex reward types interact. Category "claiming" needed explicit coordination, not implicit priority.

iOS Guest Mode Whack-a-Mole

Six related commits on May 31 alone: merge prompt added, guest sync gating, auth flash fix, alert suppression fix, spurious prompt during Google restore, didSignInInteractively flag, then automatic wallet union replacing alerts entirely (941a55d).

Lesson: Distinguishing session restoration from interactive sign-in was the root cause. The fix wasn't better prompts; it was removing prompts and merging wallets automatically.

Backend Gemini → Bedrock

5cbd76f: remove gemini package. 0dd07e4: integrate AWS Bedrock for AI-based fallback categorization of OTHER transactions. Global DynamoDB brand cache followed (5f3aa87).

Lesson: Staying AWS-native for AI after the early Gemini experiment reduced vendor sprawl and kept categorization in the same cloud as everything else.

Lessons Learned

  • Delete bravely. The Plaid removal commits weren't failures. They made room for SwiftData and modular backend routes. 4,875 backend deletions in April alone.
  • Couple repos intentionally. Schema changes, category renames, and Plaid yo-yos happened in both codebases within hours. Treat them as one product.
  • Churn is feature work. May iOS: +16,842 / −8,538 lines. May backend: +20,422 / −3,371. Refactors and tests count.
  • Incremental cache merging wasn't worth it. Backend commit 7818006 simplified insights to full-window cache hits. Simpler and correct beat clever.
  • Security reviews find real issues. c0bf3ae (opus 4.8 review) touched 28 files. IAM permissions, webhook validation, and CloudFormation lifecycle gotchas surfaced in deploys, not in design docs.
  • One-liner commits tell the truth. "can run over network." "remove sparkle." "remove plaid." "add plaid." The git log is more honest than any roadmap.
  • Stepping away is allowed. The longest flat stretch on the graph (May 10–27) was a vacation to France, not a death march. I came back and shipped the entire beta in the final week. Rest is a feature, not a bug.

Where This Leaves Monet

362 commits later, Monet is not shipped to the App Store with a semver tag. It is a working system: 14,647 lines of Swift, 12,057 lines of TypeScript, Plaid integrated twice, guest mode with certificate pinning, and an optimizer that understands Bilt 2.0, quarterly bonuses, spend caps, and RankedSpend tier assignment.

The impressionist name fits. Up close, the history looks like chaotic brushstrokes: reverts that aren't reverts, schema flip-flops, six merge-prompt fixes in one day. Step back, and a coherent picture emerges: a solo founder building the tool they wished existed, learning distributed systems and SwiftUI architecture the hard way, one commit message at a time.

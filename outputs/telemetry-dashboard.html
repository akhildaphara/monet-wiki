How to Import Telemetry Insights

Log in to TelemetryDeck

Go to your dashboard at telemetrydeck.com/dashboard and select your Monet App ID container.

Create a New Insight

Click "New Insight" on your dashboard panel. Select "Advanced JSON Query Mode" (switching out of the visual builder).

Copy and Paste TQL

Switch to the TQL Query Library tab in this dashboard, copy the desired query payload, replace YOUR_TELEMETRYDECK_APP_ID with your active ID, and paste it into the query editor.

Save and Position

Save the Insight, name it appropriately (e.g. "Active Card Wallet Sizes"), and add it to your main analytics dashboard.

Tracked Client Vocab

  • onboarding_step_viewed
    Tracks funnel: welcome, pickCards, aha
  • onboarding_cards_selected
    Tracks initial setup card volume
  • onboarding_cards_skipped
    Tracks users deferring card wallet setup
  • search_performed
    Online/Offline recommendation queries
  • recommendation_viewed
    Recommended card ID, rate, and category
  • card_added / card_removed
    Individual card selection toggles
  • card_billing_cycle_updated
    Tracks billing statement configurations
  • plaid_card_mapped
    Attributes Plaid accounts to wallet cards
  • api_error / network_error
    Captures status codes, paths, and fail messages
